DEPLOYMENT SETUP GUIDE
==============================================
Prepared for: Tanveer / Capablis Technologies
Files: index.html, trainer.html, appscript.gs
Google Sheet: https://docs.google.com/spreadsheets/d/1GN5J4R7jePjShdsGxuokBRwwnaR7QlCVoLMh__9hUlI/edit

==============================================
STEP 1 — SET UP GOOGLE APPS SCRIPT
==============================================

1. Open the Google Sheet at the link above
2. Click Extensions → Apps Script
3. Delete any existing code in the editor
4. Open the file appscript.gs and copy ALL its contents
5. Paste into the Apps Script editor
6. Click the floppy disk icon (Save) — name the project "IGI_RSP_Assessment"
7. Click Deploy → New Deployment
8. Under "Select type" choose "Web app"
9. Set:
   - Description: IGI RSP M1 Assessment Backend
   - Execute as: Me
   - Who has access: Anyone
10. Click Deploy
11. Copy the Web app URL — it looks like:
    https://script.google.com/macros/s/XXXXXXXXXX/exec
12. IMPORTANT: Keep this URL private — it is your backend endpoint

==============================================
STEP 2 — ADD THE APPS SCRIPT URL TO BOTH HTML FILES
==============================================

In BOTH index.html and trainer.html, find this line:
    const APPS_SCRIPT_URL = "PASTE_YOUR_APPS_SCRIPT_URL_HERE";

Replace PASTE_YOUR_APPS_SCRIPT_URL_HERE with the URL from Step 1.
Do this in BOTH files.

==============================================
STEP 3 — DEPLOY ON VERCEL
==============================================

Option A — Via GitHub (recommended):
1. Create a new GitHub repository: igi-rsp-assessment
2. Upload index.html, trainer.html to the repository root
3. Go to vercel.com → New Project → Import from GitHub
4. Select the repository
5. Leave all settings as default
6. Click Deploy
7. Vercel assigns a URL like: igi-rsp-assessment.vercel.app

Option B — Via Vercel CLI:
1. Install: npm install -g vercel
2. In the project folder: vercel --prod
3. Follow the prompts
